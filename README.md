## Student report generation and statistical analysis workflow automation

The tutor marks the student’s report as per the syllabus and grading requirements.

The workflow triggers and then, the following things happen:

1. **Exhibit 2:** The student progress report, which is a `heatmap` is generated by a python hook using `matplotlib` and then it is generated per student per upload of the **exhibit 1** of that particular student.
2. **Exhibit 3:** The student’s exam statistics will be generated by using some kind of a ml algorithm with workflow automation on the excel worksheet.
    - Giving three types of statistics in the thought:
        1. One for what’s weakening in the student,
        2. One for what module needs to be taken extra care of in the students learning approach, and
        3. The last one being what could be the student’s learning curve in topics based on marking.
